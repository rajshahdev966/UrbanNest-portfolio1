# 🏡 UrbanNest Interiors

> **Designing Spaces That Feel Like Home.**

A premium, cinematic interior design website crafted to demonstrate modern frontend engineering, luxury UI/UX principles, and immersive digital storytelling.

---

## ✨ Project Overview

UrbanNest Interiors is a concept website for a luxury interior design company specializing in residential, commercial, and modular interior solutions.

Rather than following a conventional agency layout, the website is designed as a visual journey—combining elegant typography, cinematic imagery, smooth animations, and conversion-focused user experiences to reflect the sophistication of high-end interior design.

---

## 🎯 Objectives

- Create a premium digital identity for an interior design brand.
- Deliver a visually immersive user experience through cinematic storytelling.
- Design a transparent and interactive project cost estimation flow.
- Showcase projects with editorial-style portfolio sections.
- Maximize user engagement and consultation conversions.
